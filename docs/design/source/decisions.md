## После брифа

| Решение | Что сделано | Где |

| ADR 033 · состояние повтора | Тест, запущенный кнопкой «повторить», идёт с тем же текстом и настройками. В строке счётчика после KPM и точности стоит отметка «повтор» (en: «repeat»): `fur-dim`, `mono-small`, контур `stroke-hair`. Отметка статична: задаётся пропом `repeat` один раз на тест, у контроллера для неё нет метода. `miss` остаётся только за ошибками. Повтор не даёт личного рекорда и не входит в график KPM по тестам; в истории он отмечен словом в столбце режима. | `TestArea`, `HistoryTable`, ScreenTest «повтор», README «Цвет» и «Экран теста» |
