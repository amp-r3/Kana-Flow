# Button

Четыре варианта: `primary`, `secondary`, `text`, `danger`.

- `primary` — заливка `fur`, текст `on-fur`. Одна на экран: «следующий тест», «продолжить урок».
- `secondary` — рамка `line-strong`. Альтернатива рядом с основной.
- `text` — `fur-dim`. Restart во время теста («заново», `enter`) и третьестепенные действия.
- `danger` — текст и рамка `miss`. Только необратимое: сброс прогресса, удаление аккаунта. Всегда ведёт в `Dialog`.
- `hint` — клавиша после подписи: `enter` у «следующего теста» и Restart, `ctrl + enter` у «завершить» в zen.
- Restart во время теста получает класс `nk-on-focus`: кнопка невидима, пока на неё не придёт фокус через `Tab`. Тогда `Enter` её нажимает.
- Высота `control-h` / `control-h-sm`, при `pointer: coarse` — от `touch-min`. Фиксированной ширины нет.
