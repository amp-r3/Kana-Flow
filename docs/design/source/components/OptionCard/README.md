# OptionCard

Вариант ответа в узнавании: номер-клавиша и кана. Выбирается мышью или клавишами `1`–`4`.

- Рамка `line-strong`, `radius-sm`, без заливки. Ховер — `bg-hover`.
- Верно — рамка `fur` и черта `eye` (`is-correct`). Неверно — `miss` с подчёркиванием `miss-dim` (`is-wrong`); тогда правильный вариант получает `is-reveal`.
- После ответа все варианты неактивны. Невыбранные уходят в `fur-dim`.
- Зелёного нет: верность читается по черте `eye` и тексту `Notice`.
