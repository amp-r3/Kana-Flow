# Dialog

Модальный диалог для выбора рядов, сброса прогресса, выхода, удаления аккаунта и жалобы.

- Нативный `<dialog>` с `showModal()`: фокус заперт внутри, `Esc` закрывает (`onClose`), страница под ним инертна. Подложка — `scrim`.
- `bg-raised`, рамка `line`, `radius-md`, без тени. Появление — `nk-reveal` за `dur-reveal`.
- Заголовок `ui-heading`, текст `ui-body` / `fur-dim`, действия справа. Безопасное действие идёт первым и получает начальный фокус.
- Необратимое действие — `Button variant="danger"`. Для удаления аккаунта кнопка неактивна, пока не введено подтверждение.
- Длинное содержимое прокручивается внутри тела, заголовок и действия остаются на месте.
