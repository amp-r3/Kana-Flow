# ResultChart

График из одной линии: накопительный KPM по секундам (результаты) или KPM по тестам (`/stats`).

- Линия `chart-kpm` 2px, сетка `chart-grid` (0, середина, верх с шагом 50), подписи осей `fur-dim`.
- Рисуется в реальную ширину контейнера (`ResizeObserver`), поэтому текст осей не масштабируется на телефоне.
- Наведение или ← → с фокусом на графике: вертикаль `chart-cursor` и тултип (`tip(i, v)`).
- Прорисовка за `dur-draw` через `stroke-dashoffset`. Это одна анимация при появлении экрана, не на горячем пути.
