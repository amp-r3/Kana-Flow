# TestArea

Поток теста: кана, каретка, буфер ромадзи, счётчик и live-показатели. Рендерится один раз на промпт; каждое нажатие идёт через контроллер, без рендеров.

**Передаёт потребитель:** `words` (кана), `mode` (`words` · `phrase` · `kana`), начальный `counter`, строки `labels` из i18n. Движок ввода получает контроллер из `onReady` и на каждое нажатие вызывает только его методы.

**Контроллер (`createTestController`)** — без фреймворка, его стоит перенести в `shared/ui` почти как есть:
- `mark(i, state)` — `className` символа, цвет меняется мгновенно (без перехода).
- `moveTo(i)` — каретка через `transform`, позиции берутся из кэша; пройденные пропускаемые символы получают `is-done`.
- `setBuffer(s)` — остаток `engine.view()` под кареткой. Буфер не сдвигает текст и прижимается к правому краю строки.
- `reject()` — отклонённая клавиша: слой каретки вспыхивает в `miss` на `dur-reject` (WAAPI, только `opacity`). При `prefers-reduced-motion` — без плавного перехода.
- `setCounter`, `setLive(kpm, acc)` — только `textContent`.
- Позиции символов кэшируются после раскладки и пересчитываются по `ResizeObserver` и `document.fonts.ready`. На горячем пути нет ни одного чтения раскладки.

**Правила**
- Пройденное — `fur`, ошибка — `miss` с чертой `miss-dim`, будущее — `untyped`, текущее отмечает каретка `eye`. Пробелы и пунктуация (`、。・！？` и т. п.) пропускаются: каретка их проходит без ввода, а после прохода они становятся `fur-dim`.
- Размеры: при ширине ≥ 640 — `jp-test` (3 строки) или `jp-solo`; уже — `jp-test-sm` / `jp-solo-sm` (2 строки), буфер в `mono-small`. Пробел едет вместе со словом, поэтому строка никогда не начинается с пробела.
- Видимое окно: высота = строки × интерлиньяж + место под буфер. Текущая строка держится второй снизу, прокрутка мгновенная.
- Live-показатели: KPM и точность рядом со счётчиком (`mono-small`, `fur-dim`). Строгость не показывается.
- Повтор (ADR 033): `repeat` ставит после показателей отметку «повтор» (`labels.repeat`): `fur-dim`, `mono-small`, контур `stroke-hair`, `radius-xs`. Она статична и задаётся один раз на тест, метода контроллера для неё нет. Красный здесь не используется: рядом с точностью его легко принять за ошибку.
- Размытие (`is-blurred`) включается только при потере фокуса окном. Фокус на Restart или ссылке тест не прерывает.
- Не добавлять: переход цвета, тряску, подложку, рамку и зелёный цвет.
