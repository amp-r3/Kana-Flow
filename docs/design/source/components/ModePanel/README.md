# ModePanel

Панель режимов на `/`: письмо, материал, строгость, тип теста, длина, слабые каны и ряды.

- Две строки по центру: «письмо | материал | строгость» и «тест | длина | слабые каны | ряды». Разделители — `line`. Две фиксированные строки вместо свободного переноса: так разделитель никогда не окажется в начале строки.
- Значения — типы движка и spec: письмо `hiragana` / `katakana` / `both`; строгость `learner` («мягкая») / `ime` («строгая IME»).
- «Длина» зависит от типа: время 15/30/60/120, количество 10/25/50/100; в zen группы нет.
- «Ряды · N …» есть только у материала «кана» и открывает `Dialog` с `RowPicker`.
- «Слабые каны» — переключатель `aria-pressed` в стиле сегмента.
- При ширине < 640 каждая группа — отдельная строка с подписью (`ui-caption`). На десктопе подписи доступны только скринридеру.
- Во время теста панель скрыта вместе с навигацией и выведена из порядка фокуса.
