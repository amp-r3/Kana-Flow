# Kbd

Клавиша в тексте: `tab`, `enter`, `esc`, `ctrl + enter`, `1`–`4`.

- `mono-small`, `fur-dim`, рамка `stroke-hair` `line-strong`, `radius-xs`. Подписи строчные, как на клавиатуре.
- Внутри кнопки — `bare` (без рамки); `Button hint` делает это сам.
- Сочетания пишутся через « + ». На macOS вместо `ctrl` показывайте `⌘`.
