# KanaChart

Таблица кан в трёх режимах: тепловая карта ошибок, тепловая карта времени реакции (`/stats`) и боксы обучения (`/learn`).

**Состав — группы `docs/spec/learning.md`, ряды по `RowId` движка:**

| блок | ряды | хирагана | катакана |
| --- | --- | --- | --- |
| основные | vowels, k, s, t, n, h, m, y, r, w_n (わ を ん) | 10 | 10 |
| звонкие | g, z, d, b, p | 5 | 5 |
| сочетания | ky, sh, ch, ny, hy, my, ry, gy, j, by, py | 11 | 11 |
| расширенные | ext_fa, ext_va, ext_wi, ext_ti, ext_che | — | 5 |
| **итого групп / кан** | | **26 / 104** | **31 / 125** |

Основные и звонкие ряды выровнены по колонкам a·i·u·e·o (у `y` пропуски). `w_n` идёт подряд: わ を ん. Сочетания и расширенные ряды выводятся подряд. Двухзнаковая кана набрана `jp-cell-sm`, чтобы помещаться в ячейку 44px. Состав рядов берите из `kanaRows(script)` и `kanaOf(script)` — компонент не держит своих списков.

| режим | ступени | текст в ячейке |
| --- | --- | --- |
| `miss` — доля ошибок | `heat-miss-1…5` (> 0, 3, 7, 12, 20%) | 1–3 `fur`, 4–5 `on-fur` |
| `time` — реакция, мс | `heat-fur-1…5` (< 450, 600, 750, 950, больше) | 1–3 `fur`, 4–5 `on-fur` |
| `box` — бокс 1–5 | `heat-fur-1…5`; 4–5 = освоена, черта `eye` под ячейкой | то же |

- Нет данных или кана не введена — только рамка `line`, кана `fur-dim`. 0 ошибок — без заливки. Бокс 0 — рамка `line-strong`. Заблокирована — `fur-faint`, `aria-disabled`.
- На `/learn` группы открываются по порядку таблицы: всё после группы текущего урока заблокировано. «Освоено N из M» = каны в боксе ≥ 4 / `kanaOf(track).length`.
- Каждая ступень держит текст ≥ 4,5:1. Значение не передаётся одним цветом: оно есть в тултипе и в `aria-label` ячейки.
- `role="grid"`, ячейки — кнопки с роуминговым `tabIndex`. ← → идут по порядку, ↑ ↓ — в ближайшую колонку соседнего ряда, в том числе между блоками.
- Блоки стоят в ряд и переносятся; на 360px всё идёт в одну колонку (самый широкий ряд, `ext_ti`, — 6 ячеек, 320px).
