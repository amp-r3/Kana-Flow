# EmptyState

Пустое состояние: кошка, заголовок, пояснение, одно действие. Используется для пустой статистики и для 404 (`mood="neutral"`).

- Кошка `geometry` 112px, по умолчанию спящая.
- Заголовок `ui-heading` констатирует, текст `ui-body` / `fur-dim` говорит, что делать. Действие — одна `primary` с подсказкой клавиши.
