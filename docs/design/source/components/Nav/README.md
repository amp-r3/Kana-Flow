# Nav

Верхняя панель: знак и «nekotype» слева; «тест · обучение · статистика · настройки»; справа `en/ru` и «войти».

- Ссылки `ui-label`: `fur-dim` → `fur`, активная — `fur` + `aria-current`.
- «войти» ведёт в `/settings`. После входа или на preview-окружениях — `loginLabel={null}`. «Сбросить прогресс» живёт в `/settings`, «о проекте» — в `Footer`.
- `hidden` во время теста: затухание за `dur-fade`, затем `visibility: hidden` и `inert`. Первый `Tab` попадает на Restart.
- Возврат навигации: после конца теста и при движении мыши дальше 8px — снять `hidden`.
- Ширина < 640: знак и `en/ru` + «войти» в первой строке, ссылки — во второй, растянуты по ширине. Цели касания от `touch-min`.
