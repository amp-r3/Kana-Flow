# Stat

Метрика: подпись, число и единица.

- `size="hero"` — KPM, одна на экран: `mono-hero`, при ширине < 640 — `mono-hero-sm`. Остальные метрики — `mono-stat`.
- Набор результата (spec `metrics.md`): KPM, точность по кане, IPM (только слова и фразы), точность нажатий, ошибки, лучшая серия, время. Других метрик на результатах нет.
- `badge` — место для `PersonalBestBadge` рядом с подписью KPM.
- Без цветовой оценки: число всегда `fur`.
